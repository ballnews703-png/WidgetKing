📱 Put it on your iPhone (no Mac needed)

  1. Install the free Scriptable app from the App Store.
  2. Design your widgets above, then tap Copy Scriptable Script (or Download it and send it to your phone via Notes, email, or messages).
  3. In Scriptable, tap +, paste the script, and name it WidgetKing.
  4. Long-press your Home Screen → Edit → Add Widget → search Scriptable → add a widget.
  5. Long-press the new widget → Edit Widget → set Script to WidgetKing, and set Parameter to a design's name to choose which one it shows. Add more widgets with different parameters — designs are fully interchangeable.
  6. Changed your designs? Copy the script again and paste over the old one in Scriptable.

Note: iOS refreshes Scriptable widgets on its own schedule (every few minutes), so clock widgets are close but not to-the-second. Everything runs on your devices — nothing is uploaded anywhere.
