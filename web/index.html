Put it on your iPhone (no Mac needed)

💡 Make this designer feel like an app: in Safari tap Share → Add to Home Screen — you'll get a WidgetKing 👑 icon that opens full-screen.

The full instructions, if you prefer reading
  1. Install the free Scriptable app from the App Store.
  2. Design widgets above, then tap Copy Scriptable Script.
  3. In Scriptable, tap +, paste, and name it WidgetKing.
  4. Long-press your Home Screen → Edit → Add Widget → search Scriptable → add a widget (use Medium/Large for launchers so every icon is tappable).
  5. Long-press the widget → Edit Widget → Script: WidgetKing, and set Parameter to a design's name. Different widgets can show different designs.
  6. Glass / Clear backgrounds: follow the ✨ step in the wizard above (one-time wallpaper photo; Clear also wants Parameter Name | position).
  7. Changed your designs? Copy the script again and paste over the old one.

iOS refreshes Scriptable widgets on its own schedule (every few minutes), so clock and battery values are close but not live to-the-second. Everything runs on your devices — nothing is uploaded anywhere.

📖 How to put these on your Home Screen (one-time per app)
  1. Open the Shortcuts app → tap +.
  2. Add the action “Open App” → tap the pale word App → pick the app (e.g. Instagram).
  3. Tap the share icon at the bottom → Add to Home Screen.
  4. Tap the small icon next to the name → Choose Photo → pick your new icon.
  5. Name it (just “Instagram”) → Add. Done! Repeat per app.
  6. Optional: hide the original icon (long-press → Remove from Home Screen — it stays in your App Library).

⚡ Your Shortcut Guide

Auto-generated from the widgets you've saved: what each app button does on tap, and the exact Shortcuts to create for the few that need one. (Apple doesn't let any app install Shortcuts for you — this reads your designs so there's zero guesswork.)

⚡ Zero-flash tip: widget taps normally hop through Scriptable for a moment. For a widget that opens one app, skip that entirely: long-press the widget → Edit Widget → When Interacting → Open URL → paste the app's link (copy buttons below). iOS then opens the app directly — Scriptable never appears. Multi-icon launchers can't do per-icon direct taps (a Scriptable limit), so for a flash-free grid use the App Icon Maker above.
