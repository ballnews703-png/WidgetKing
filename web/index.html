4 Put it on your iPhone (no Mac needed)

  1. Install the free Scriptable app from the App Store.
  2. Design widgets above, then tap Copy Scriptable Script.
  3. In Scriptable, tap +, paste, and name it WidgetKing.
  4. Long-press your Home Screen → Edit → Add Widget → search Scriptable → add a widget (use Medium/Large for launchers so every icon is tappable).
  5. Long-press the widget → Edit Widget → Script: WidgetKing, and set Parameter to a design's name. Different widgets can show different designs.
  6. Glass / Clear backgrounds (one-time): long-press your Home Screen, swipe to the last empty page, take a screenshot. Then open the WidgetKing script inside Scriptable, run it (▶), choose Set wallpaper photo… and pick that screenshot. For pixel-perfect Clear widgets, set the widget Parameter to Name | position — e.g. My Clock | top-left (small: top/middle/bottom-left/right; medium & large: top, middle, bottom). Glass looks great without a position.
  7. Changed your designs? Copy the script again and paste over the old one.

iOS refreshes Scriptable widgets on its own schedule (every few minutes), so clock and battery values are close but not live to-the-second. Everything runs on your devices — nothing is uploaded anywhere.
